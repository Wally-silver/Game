# Weird Rule Town

Cocos Creator 3.8.8 game project.

## Project structure

- `assets/scenes`: Scene assets for launch, home, battle, and result flows.
- `assets/scripts/core`: App bootstrap and shared runtime state.
- `assets/scripts/models`: Data models used by gameplay systems and UI.
- `assets/scripts/systems`: Game rule, event, resident, and report systems.
- `assets/scripts/ui`: Scene and popup UI controllers.
- `assets/scripts/config`: JSON configuration for buildings, residents, events, and rules.
